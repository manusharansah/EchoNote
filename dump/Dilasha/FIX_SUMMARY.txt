================================================================================
COMMON ISSUES & FIXES
================================================================================

Issue: "Cannot connect to Ollama"
Fix: Make sure `ollama serve` is running in another terminal

Issue: "Model 'llama3' not found"
Fix: Run `ollama pull llama3`

Issue: "Ollama request timed out"
Fix: Try faster model: set OLLAMA_MODEL=mistral in .env

Issue: "Transcription resulted in empty text"
Fix: Audio may be too short or quiet - try longer recording

Issue: Stuck on "SUMMARIZING" stage
Fix: Check backend logs for exact error message
     If Ollama issue: restart Ollama or try different model
